# 你拒絕，我給錢

藝評稿酬罷工基金的計畫網站。線上位置：https://refuse.fabdao.world/

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站本體。除非要改版面或文案，平常不用動。 |
| `data.json` | 網站顯示的所有內容：稿酬表、公開帳本、文章、設定。**更新網站＝只改這個檔。** |
| `og.png` | 分享到臉書、LINE 時的預覽圖。 |
| `CNAME` | 自訂網域設定，請勿刪除。 |

## 怎麼更新網站內容

1. 打開 https://refuse.fabdao.world/#edit （後台只靠這個網址開啟，沒有連結指向它）
2. 在「公開內容」「設定」分頁編輯，或在「案件」分頁貼上案件庫匯出的代碼
3. 按「預覽公開頁」確認
4. 按「產生 data.json」，複製整段內容
5. 回到這個 repo 打開 `data.json` → 點鉛筆圖示 → 全選刪除 → 貼上 → Commit changes
6. 約一分鐘後網站更新。回到後台按「已更新完成」

後台只在你的瀏覽器裡運作，不會自己送出任何東西。別人就算發現 `#edit` 也改不了網站——改網站一定要能 commit 這個 repo。
